TempFlow : Temperature Converter Website 🌡️

TempFlow is a sleek, modern, and responsive real-time temperature conversion web application built with HTML5, CSS3, and JavaScript. It allows users to seamlessly convert values between Celsius, Fahrenheit, and Kelvin with built-in validation rules.

✨ Features
* Multi-Unit Support: Convert values instantly between Celsius (°C), Fahrenheit (°F), and Kelvin (K).
* Absolute Zero Validation: Smart validation that prevents invalid inputs below theoretical absolute zero limits for each unit.
* Modern UI/UX: Clean, dark-themed layout featuring glowing background effects, interactive tab selection, and FontAwesome icons.
* Responsive Design: Adapts smoothly across various device screens (desktop, tablet, and mobile).

🛠️ Built With
HTML5 - Semantic markup and layout structure
CSS3 - Styling, variables, animations, and responsive design
JavaScript (ES6+) - Core conversion logic, real-time input handling, and validation
